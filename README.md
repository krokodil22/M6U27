# КосмоКод: переменные

Интерактивный браузерный тренажёр для детей 9–13 лет. Пять миссий последовательно знакомят с созданием, записью, чтением и изменением переменных через Blockly.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Для production-сборки используйте `npm run build`.

Прогресс сохраняется в `localStorage` текущего браузера. Кнопка «Сбросить прогресс» удаляет сохранение.
